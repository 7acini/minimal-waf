# Security policy

Please do not publish exploitable bypasses or vulnerabilities before a fix is
available. Report them privately through GitHub's **Security → Report a
vulnerability** flow for this repository.

Include the affected version, request sample, expected behavior, observed
behavior and any proposed mitigation. Do not include production credentials,
session cookies or personal data.

The project is a defense-in-depth control. A bypass in a signature does not
imply that the protected application is safe; the underlying vulnerability
must still be fixed.
